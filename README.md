# 统一 CG 演出回放库（Unified CG Replay Library）

> 实现文档集 · 架构冻结版 v1.0 · 2026-10-15

## 这是什么

把已解包的 galgame 资源**裁剪**成"只够重演 CG 事件"的最小集合，装进**一套自研回放应用**，从而在**完整重温 CG 演出**的同时**大幅降低硬盘占用**。

本文档集是上游《FINAL_统一CG演出回放库_架构冻结与执行提示词.md》第 13 节「交给实现方（AI）的输出要求」的落地成果：**七份文档 + 三份机器可读 schema**。上游文档第 3 节的七轮 drill 结论**已冻结**，本文档集只做细化，不推翻决策。

## 六条硬约束（摘自上游文档第 14 节「禁忌」，全文见 07 文档）

1. ❌ 禁止擅自删除原资源；一切删除须经**待删区 + 保留期**或明确的 per-game 开关
2. ❌ 禁止在 M0 清点前承诺具体降幅
3. ❌ 禁止过度设计 —— **不做通用引擎模拟器**，只做 IR 回放
4. ❌ 禁止有损转码
5. ❌ 禁止把库锁死在单一网盘
6. ❌ 禁止把「内嵌索引」做成「资源冗余」（重复的只能是 KB~MB 级索引）

## 变更管理

第 3 节决策为**架构冻结**状态。任何对 DR-1 ~ DR-37 的修改必须走**架构变更单**（07 文档 §7），评审通过后同步更新本文档集全部受影响文档与 schema，并在 07 文档留痕。未经变更单，实现方不得自行放宽硬约束。
