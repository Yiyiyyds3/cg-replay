# 03 · IR 规范（统一演出中间表示）

| 项目 | 内容 |
|---|---|
| 文档版本 | v1.0（架构冻结） |
| 配套 | schema/ir.schema.json（机器可读，与本文档同源） / 04 适配器 / 06 客户端 |
| 地位 | **核心枢纽**：回放器只有一套，永远只吃 IR；新增引擎 = 只写「脚本→IR 翻译器」+「转场注册表」；裁剪由 IR 反推 |

---

## 1. 设计原则

1. **单一消费者**：回放器只吃 IR，不认任何引擎专有格式。
2. **确定性**：同一 IR 在任何机器上重演结果一致（时间轴绝对排序、无隐式状态）。
3. **可反推**：IR 内每个资源引用都可被裁剪器收集（裁剪与解析同一投入）。
4. **可降级**：认不出的转场 → 回退 L0；认不出的指令 → 保守保留资源 + 标记，**永不崩**。
5. **语言无关**：IR 是 JSON，任何语言的适配器都能产出/消费。

---

## 2. 顶层结构

```json
{
  "ir_version": "1.0",
  "game_id": "string",
  "engine_id": "string",
  "fidelity": "generic | tuned | exclusive",
  "meta": {
    "script_encoding": "string，可空，如 utf-16le / shift_jis",
    "generated_by": "string，适配器标识",
    "generated_at": "ISO 8601"
  },
  "events": [ Event ]
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `ir_version` | string | 是 | 固定 "1.0"；破坏性变更升版本号并配套迁移 |
| `game_id` | string | 是 | 与包 `package.json.game_id` 一致 |
| `engine_id` | string | 是 | 产出本 IR 的引擎 |
| `fidelity` | string | 是 | 本 IR 实际达到的保真度（`tuned` 才允许含引擎专有转场参数） |
| `meta` | object | 是 | 溯源信息 |

## 3. Event（事件 = 一个可重演演出单元）

```json
{
  "event_id": "evt_000012",
  "kind": "still_cg | event_video | scene | other",
  "title": "string，可空",
  "ord": 12,
  "start_ms": 0,
  "end_ms": 18500,
  "characters": ["彼女"],
  "layers": [ Layer ],
  "timeline": [ TimelineOp ],
  "texts": [ TextLine ],
  "voices": [ Voice ],
  "transitions": [ Transition ],
  "branches": [ Branch ],
  "unrecognized": [ Unrecognized ],
  "assets": [ AssetRef ]
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `event_id` | string | 是 | 包内唯一，`evt_` 前缀 + 6 位序号 |
| `kind` | enum | 是 | `still_cg` 静帧 CG / `event_video` 事件视频 / `scene` 场景演出（含立绘对话）/ `other` |
| `title` | string | 否 | 展示名（缺省由客户端按序号生成） |
| `ord` | int | 是 | 游戏内演出顺序（回放列表排序键） |
| `start_ms` / `end_ms` | int | 否 | 演出时间窗（由 timeline 推导，冗余存储便于 UI） |
| `characters` | string[] | 否 | 出场角色（中心库 `characters` 表来源） |
| `layers` | Layer[] | 是 | 图层定义（可空数组） |
| `timeline` | TimelineOp[] | 是 | 时间轴指令，**按 t_ms 升序** |
| `texts` | TextLine[] | 是 | 台词（DR-3） |
| `voices` | Voice[] | 是 | 语音 |
| `transitions` | Transition[] | 是 | 本事件用到的转场（可空） |
| `branches` | Branch[] | 是 | 分支点（可空） |
| `unrecognized` | Unrecognized[] | 是 | 未识别指令登记（可空） |
| `assets` | AssetRef[] | 是 | **本事件全部资源引用的去重并集**（裁剪器直接消费） |

## 4. Layer（图层）

```json
{
  "layer_id": "cg",
  "kind": "background | stand | cg | mask | movie | text | effect",
  "asset": { "hash": "...", "orig_path": "evimage/cg012.tlg", "role": "cg" },
  "z": 10,
  "visible": false,
  "transform": {
    "x": 0, "y": 0,
    "scale": 1.0,
    "rotation": 0.0,
    "opacity": 1.0,
    "anchor": "top-left | center"
  },
  "blend": "normal | add | multiply"
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `layer_id` | string | 是 | **事件内唯一**（校验规则 V2） |
| `kind` | enum | 是 | `background` 背景 / `stand` 立绘（含差分）/ `cg` 事件图 / `mask` 掩膜 / `movie` 视频 / `text` 文本框 / `effect` 特效层 |
| `asset` | AssetRef \| null | 否 | 资源引用；`text`/`effect` 层可为 null |
| `z` | int | 是 | 叠放次序，大者在上 |
| `visible` | bool | 是 | 初始可见性 |
| `transform` | object | 否 | 初始终态；各字段可缺省（缺省=单位值） |
| `blend` | enum | 否 | 混合模式，默认 `normal` |

## 5. TimelineOp（时间轴指令）

**时间基准**：`t_ms` 为相对事件开始的毫秒数，整数 ≥ 0，整个 timeline 按 `t_ms` 非降序排列（校验规则 V3）。回放器是一个**确定性解释器**：按序执行、到点触发、不并行推进除音视频外的任何状态。

```json
{ "t_ms": 0, "op": "layer_show", "target": "cg", "params": { "opacity": 1.0, "duration_ms": 0 } }
```

| op | params | 语义 |
|---|---|---|
| `bgm_play` | `{asset, loop: bool, volume: 0~1}` | 播放 BGM（DR-16：BGM 全保留） |
| `bgm_stop` | `{fade_ms?}` | 停 BGM |
| `se_play` | `{asset, volume}` | 音效 |
| `voice_play` | `{asset}` | 语音（与 `texts` 的 `line_id` 对应关系见 §6） |
| `voice_stop` | `{}` | 停语音 |
| `layer_show` | `{target, opacity, duration_ms}` | 显示图层（可带淡入） |
| `layer_hide` | `{target, opacity, duration_ms}` | 隐藏图层（可带淡出） |
| `layer_set` | `{target, transform 部分字段}` | 设置图层属性 |
| `layer_move` | `{target, x, y, duration_ms, easing?}` | 位移（缓动可缺省=linear） |
| `layer_fade` | `{target, from, to, duration_ms}` | 透明度过渡 |
| `layer_scale` | `{target, from, to, duration_ms}` | 缩放过渡 |
| `layer_rotate` | `{target, from, to, duration_ms}` | 旋转过渡 |
| `transition_begin` | `{transition_id?, impl?, duration_ms, params?}` | 开始一次转场（见 §7） |
| `transition_end` | `{}` | 转场结束 |
| `text_show` | `{target: line_id}` | 显示某条台词（含文本框） |
| `text_hide` | `{}` | 隐藏文本框 |
| `movie_play` | `{asset, loop}` | 播放事件视频 |
| `movie_stop` | `{}` | 停视频 |
| `quake` | `{duration_ms, amplitude}` | 屏幕震动（通用近似） |
| `wait` | `{duration_ms}` | 空等（保时序用） |
| `label` | `{name}` | 命名锚点（调试模式跳转目标） |
| `unrecognized` | `{raw, reason}` | 未识别指令（见 §8） |

**规范要求**：适配器**只能**使用上表 op；需要新 op 必须升级 `ir_version` 并同步回放器与 schema（走架构变更单）。

## 6. TextLine / Voice（文本与语音）

```json
{
  "line_id": "line_1",
  "t_ms": 1000,
  "speaker": "彼女",
  "text": "欢迎回来。",
  "voice": { "hash": "...", "orig_path": "voice/v012_1.ogg", "duration_ms": 1800 },
  "style": {
    "font_hint": "string，可空",
    "size_px": 28,
    "position": "bottom | center | top",
    "color": "#ffffff",
    "name_box": true
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `line_id` | string | 是 | 事件内唯一；`timeline.text_show.target` 必须指向它（校验规则 V4） |
| `t_ms` | int | 是 | 台词出现时刻 |
| `speaker` | string | 否 | 说话人（中心库 `text_lines.speaker` 与角色检索来源） |
| `text` | string | 是 | 台词原文（DR-3；全文检索索引对象） |
| `voice` | object \| null | 否 | 语音引用（`hash` + `orig_path` + `duration_ms`） |
| `style` | object | 否 | 排版近似提示（§9：文字排版只能近似） |

**一致性规则**：`voice` 非 null 时，`voices[]` 中必须有一条同 `line_id` 的记录（适配器负责，schema 校验 V5 兜底）。语音与台词的时序由 `voice_play` / `text_show` 两条 op 承载。

## 7. Transition（转场）与回退规则

```json
{
  "transition_id": "crossfade",
  "impl": "fade",
  "duration_ms": 800,
  "params": {}
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `transition_id` | string | 是 | 引擎原生转场标识（如 KiriKiri `trans method=` 的值） |
| `impl` | string | 是 | 核心注册表中的实现键；**未实现时由适配器填 `"fade"` 并标记 `fallback: true`** |
| `duration_ms` | int | 是 | 时长（引擎缺省时适配器给默认值） |
| `params` | object | 否 | 实现参数（如方向、缓动） |
| `fallback` | bool | 否 | true = 本条已发生 L0 回退（回放器可提示用户） |

**回退规则（04 文档 §5 有完整契约）**：

1. `impl` 必须是核心 L0 注册表成员：`fade` / `slide_left` / `slide_right` / `zoom` / `wipe`。
2. `tuned` 级适配器可注册引擎专有 impl；未注册的 `transition_id` → 自动映射到 `fade`（淡入淡出近似）+ `fallback: true`。
3. 回放器遇到 `fallback: true` 的转场时**不得报错**，仅在调试模式标注"近似转场"。

## 8. Branch / Unrecognized（分支与未识别）

```json
"branches": [
  {
    "branch_id": "br_1",
    "t_ms": 12000,
    "type": "choice | flag | jump",
    "options": [ { "text": "沉默", "target_event": "evt_000013" } ],
    "default_target": "evt_000013",
    "chosen": null
  }
]
```

**分支语义**：回放是**重演**而非重玩——默认沿 `default_target` 走；调试模式允许人工切换分支（06 文档 §4.3）。`chosen` 记录人工回放时的选择（null = 未记录/走默认）。

```json
"unrecognized": [
  {
    "node_path": "timeline[7]",
    "raw": "[some_exotic_tag storage=foo/bar.tlg]",
    "reason": "unknown_tag",
    "kept_assets": ["<hash>"]
  }
]
```

**未识别语义（裁剪安全原则，§9-6）**：适配器认不出的指令 → 原文照录 + 收集其中"看起来像路径"的操作数 → 在原归档中解析得到的一律**保守保留**并在此登记。`kept_assets` 必须与 `assets[]` 对得上（校验规则 V6）。

---

## 9. AssetRef（资源引用）

```json
{ "hash": "64位hex", "orig_path": "evimage/cg012.tlg", "role": "cg" }
```

| 字段 | 说明 |
|---|---|
| `hash` | BLAKE3 hex，指向包内 `assets/<h[:2]>/<h>` |
| `orig_path` | 原归档相对路径（溯源 / 完整性侧录对账） |
| `role` | `background | stand | cg | voice | bgm | se | movie | text_asset | unrecognized` |

---

## 10. 校验规则（MUST，摄入时强制执行）

| # | 规则 | 违反时 |
|---|---|---|
| V1 | `assets[]` 中每个 hash 必须存在于包 `hashes.txt` | 摄入失败（误裁检测第一层） |
| V2 | `layers[].layer_id` 事件内唯一 | 摄入失败 |
| V3 | `timeline` 按 `t_ms` 非降序 | 摄入失败 |
| V4 | `text_show.target` 必须存在于 `texts[]` | 摄入失败 |
| V5 | `voice.line_id` 必须存在于 `texts[]` | 摄入失败 |
| V6 | `unrecognized[].kept_assets` ⊆ `assets[]` | 摄入失败 |
| V7 | `transitions[].impl` ∈ L0 注册表 或 `fallback=true` | 摄入失败 |
| V8 | 顶层 `fidelity` ∈ 枚举；`tuned` 才允许非 L0 impl | 摄入失败 |

## 12. 与其他文档的关系

- **02 数据模型**：IR 是包内文件之一；`assets[]` 即 `refs.json` 的事件级来源。
- **04 适配器**：`build_IR()` 的产出必须满足本文档全部 MUST；转场回退规则见其 §5。
- **06 客户端**：回放器 = timeline 解释器；调试模式逐句/逐图层直接映射到 `texts` / `layers`。
