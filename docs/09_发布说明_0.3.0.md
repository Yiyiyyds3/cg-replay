# cg-replay 0.3.0 · 多游戏库 MVP

> 模板：每个版本发布时复制本文件改内容。**发布前必须由用户测试通过并许可**。

## 这是什么

一个把 galgame 的 CG / 场景 / 演出段落**按原作自己的分割方式**重演出来的桌面播放器
（Windows）。不还原游戏画面，只做「原作事件库 + 逐帧重演 + 导出」。

## 这一版能做什么

- **多游戏库**：登记多款解包目录，左侧游戏栏切换；每款游戏独立事件库与封面
- **跨游戏卡片墙**：「全部」页签把各游戏的 CG / 场景 / 段落铺成卡片墙，
  顶部搜索框按**游戏名 / 事件标题**筛选
- **收藏三级**：游戏 / 事件 / 角色都能收藏，各带 1~5 星评分与备注；
  角色来自台词聚合（本作 33 位说话人）
- **导出任务中心**：GIF（10fps / 480×360 / 15s）与 MP4（25fps / 960×720 / 60s，
  走本机 ffmpeg）；异步执行，有进度与帧数、**可取消**
- **安装包**：NSIS 每用户安装（无 UAC，不写 Program Files），数据落在
  `%LOCALAPPDATA%\cgreplay-ui`
- **最近播放**：按天分组，可一键清理 3 天前（可设「启动自动清理」）

## 安装

1. 下载 `cgreplay-ui-amd64-installer.exe`
2. 双击安装（每用户，无需管理员）
3. 启动后在左侧「添加游戏」登记**已解密解包**的游戏目录

> 安装包未做代码签名：首次运行 Windows 可能弹 SmartScreen，点「更多信息 → 仍要运行」。

## 已知限制

- 导出**无音轨**
- 台词全文检索已撤除（角色区仍可用）
- 目前只有「重返蓝鲸岛」一款真实语料验证过
- 需系统已装 WebView2 运行时（Win11 自带；Win10 缺失时安装包会引导安装）
