## 2. 库首页（游戏分组）

**布局**：卡片墙，每游戏一张卡片：

- 封面缩略图（事件首选封面，WebP，LRU 缓存）
- 标题（原文标题副显）
- 徽标行：引擎 / `fidelity` 档位 / 模式（旁挂·接管）/ 事件数 / 库内占用
- 状态角标：`has_emote`（含不可复刻项）/ 存在未识别指令 / 缺资源告警

**交互**：

- 排序：最近回放 / 标题 / 引擎 / 占用；筛选：引擎、fidelity、模式、收藏
- 卡片右键：模式开关（旁挂↔接管，带后果提示）、回灌、冷归档、打开目录
- 空态：引导至摄入（05 文档阶段 B）

**规模适配（DR-32）**：分页/虚拟滚动；2,081,409 文件量级下首页只读中心库，不扫盘。

---

## 3. 游戏详情与事件浏览

- 双视图：**网格**（缩略图）/ **列表**（标题、类型、时长、台词首句）
- 筛选：事件类型（still_cg / event_video / scene）、角色、收藏、含未识别
- 事件元信息：缩略图、标题、起止时间、出场角色、语音/BGM 有无
- **台词全文搜索命中**在此页高亮定位，点击直达回放器对应句

---

## 4. 回放器（C3 完整演出）

### 4.1 舞台与演出

- 舞台 = 图层画布：按 IR `layers`（z 序）+ `timeline` 确定性重演：背景 → 立绘 → CG → 文本 → 语音 → BGM → 转场
- 文本框：按 `texts[].style` 近似渲染（§9：排版只能近似）；说话人名框
- 音频：语音 + BGM 同步播放（按需解码，原格式直播）
- 视频层：`event_video` 事件整屏播放

### 4.2 控制条与快捷键

| 功能 | 快捷键 | 说明 |
|---|---|---|
| 播放/暂停 | Space | — |
| 下一句 | → / N | 跳到下一个 `text_show` |
| 上一句 | ← / P | — |
| 跳句 | 点击进度条上的句标记 | 进度条按 `texts` 刻度 |
| 跳到事件首/尾 | Home / End | — |
| 快进/退 ±5s | ↑ / ↓ | — |
| 全屏 | F11 | — |
| 导出静帧 | F12 | 当前舞台帧 → PNG |
| 调试模式 | D | 打开/关闭调试面板 |

### 4.3 调试模式（DR-29）

- **逐句**：单步执行 `text_show`；显示当前 line_id、t_ms、原文
- **逐图层**：图层树（layer_id / kind / z / 可见性），可显隐、隔离单层
- **逐指令**：时间轴逐 op 步进，高亮当前 op 与目标图层
- **跳句**：任意 line 跳转；`label` 锚点可作跳转目标
- **显示图层**：debug overlay 画图层边界 + 资源信息（hash、orig_path、尺寸）
- **转场标注**：`fallback=true` 的转场显示「近似转场」徽标
- **缺资源告警**：缺任何 asset 时**必须**在舞台顶部常驻横幅 + 日志落库（DR-35 第二层，不得静默失败）

### 4.4 分支处理

- 默认沿 `branches[].default_target` 重演（重演非重玩）
- 调试模式下可人工切换分支，选择写入 IR `chosen`（仅会话内生效，不改包）

## 5. 检索（DR-28）

全局搜索框 + 多维筛选：

| 维度 | 实现 |
|---|---|
| 台词全文 | SQLite FTS5（`text_lines_fts`），支持分词/前缀 |
| 游戏 | `games.title/original_title` |
| 角色 | `characters` + 事件出场 |
| 引擎 | `games.engine_id` |
| 收藏 | `favorites` |

- 结果分组展示（游戏 → 命中事件 → 命中句），点击直达回放器并定位到句
- 搜索历史本地保存

---

## 6. 收藏体系（DR-31）

- **收藏**：游戏 / 事件 / 角色三级
- **评分**：1~5 星
- **备注**：自由文本（事件级最常用）
- **重温清单**：playlist，可拖拽排序、连续回放、重命名
- 入口：事件卡片「☆」、详情页批量为清单追加

---

## 7. 导出（DR-30）

| 类型 | 实现 | 约束 |
|---|---|---|
| 静帧 | 当前舞台帧 → PNG | — |
| GIF | 回放过程录帧 → GIF | 限时提示（长事件体积警告） |
| 视频 | 回放过程录制 → MP4（ffmpeg sidecar） | 编码参数可选 |

**红线**：导出是回放的**派生物**，不触碰库内原资产；导出失败不影响库（FR-10）。导出任务进后台任务中心，可暂停/退出。

---

## 8. 后台任务中心（DR-10 / DR-32）

- 任务类型：扫描 / 哈希 / 缩略图 / 校验 / 摄入 / 冷归档导出 / 回灌 / 去重
- 每任务：进度条（done/total）、开始时间、暂停/继续/退出按钮、错误信息
- 全局：全部暂停/退出；任务状态持久化（`jobs` 表），重启恢复
- 日志视图：结构化日志流，可导出

## 9. 设置与库管理

### 9.1 per-game 模式开关（DR-6 / DR-14）

- 每游戏：`旁挂` / `接管`（默认接管）
- 切换到接管时明确提示：原归档将进入 a→b 两段删除流程（05 文档阶段 F）
- `keep_archive=1`（还会玩）的游戏：UI 锁定为旁挂，提示"删了资源游戏起不来"

### 9.2 待删区（DR-36）

- 列表：路径、大小、原因、剩余时间（**72h 倒计时**）
- 操作：恢复 / 立即销毁（**二次确认 + 输入确认**）
- 到期自动真删，记录存档

### 9.3 冷归档（DR-9）

- 生成待上传清单（含 content_hash、体积、云端校验码）
- 上传前**加密**（口令本地保管，仅存 `key_hint`）
- 人工/第三方工具上传后回填记录：云端服务 / 云端路径或标识 / 上传时间 / 云端校验码 / 回下载方式
- 支持多网盘并存（禁止锁死单一服务）

### 9.4 保真度与 E-mote（DR-22 / FR-19）

- 查看每游戏 `fidelity`；标注 tuned 升级计划
- `has_emote` 游戏与事件显示「此项不可复刻」徽标

## 10. 状态、告警与错误

| 场景 | 表现 |
|---|---|
| 缺资源（误裁检测第二层） | 回放器舞台顶部常驻横幅 + 任务中心告警条目 |
| 哈希不符 | 明确报错并定位文件，禁止静默跳过（FR-12） |
| 未识别指令 | 事件角标 + 详情页列表（可查看 raw 与保守保留清单） |
| 近似转场 | 调试模式徽标（普通模式不打扰） |
| unknown 引擎游戏 | 库首页单独分组"待人工处理" |

## 11. 性能与规模适配（DR-32 / NFR）

| 项 | 措施 |
|---|---|
| 208 万文件 | 首页/详情只读 SQLite，不扫盘；扫描只发生在摄入与设置页主动触发 |
| 缩略图 | WebP + LRU 内存缓存 + 磁盘缓存；后台可重建 |
| 大列表 | 虚拟滚动 + 分页（每页 60） |
| 解码 | 按需解码（TLG/HG3/SGCG/OGG/视频），解码结果短时缓存 |
| 启动 | 双击 exe 直接用；首帧 < 2s（库加载走 SQLite mmap） |
