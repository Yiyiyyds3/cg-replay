# cg-replay 0.4.0 迭代计划

## 一、版本目标

0.4.0 聚焦四个方向：

1. 修复解包产物 CG 分类错位与纯黑界面误判
2. 修复 CG 预览图截取入场黑屏
3. 新增回放点击互动与文本/音频呈现
4. 工作区与导航栏 VSCode 风格重构

对应里程碑：0.4.0（目标建在 GitHub，见下文「GitHub 执行记录」）。

## 二、四项工作与验收标准

### 1. [Bug] 解包后 CG 分类错位与纯黑界面误判

- 背景：解包产物分类错位导致 CG/背景/立绘/影片混杂；纯黑帧被当成有效画面，可能触发交互或会话拒绝。
- 验收标准：
  - 解包产物按 CG / 背景 / 立绘 / 影片 正确分目录；
  - 纯黑帧不得被当成有效画面，不触发交互、不触发会话拒绝；
  - 分类与黑帧判定补单测。
- 分支：`fix/unpack-classify-black`

### 2. [Bug] CG 预览图截取入场黑屏

- 背景：封面/预览图取到时间轴开头（入场段），显示为黑屏。
- 验收标准：
  - 封面/预览取时间轴中的有效画面（非入场黑屏）；
  - 不再显示入场黑屏；
  - 补单测（含黑帧过滤逻辑）。
- 分支：`fix/cover-frame`

### 3. [Feature] 回放点击互动与文本/音频

- 背景：当前回放是纯观看，缺少原作点击推进、台词与语音。
- 验收标准：
  - 鼠标点击舞台触发一次推进；
  - CG / 事件回放能看到台词并听到语音；
  - 补测试（推进状态机 + 文本/音频链路）。
- 分支：`feat/click-av`

### 4. [Design] 工作区与导航栏 VSCode 风格重构

- 背景：现有前端布局与主流编辑器习惯不一致，需要 VSCode 风格。
- 验收标准：
  - 活动栏 + 侧栏 + 标签页 + 状态栏 的深色布局；
  - 预览窗与导航布局优化；
  - `npm run build` 通过。
- 分支：`feat/vscode-ui`

## 四、分支与 PR / 合并策略

- 每项独立分支（命名见上文），从最新 main 切出。
- 分支 → PR → review → squash 合并回 main；禁止直接 push main。
- 合并顺序：两个 Bug 修复先行（`fix/unpack-classify-black`、`fix/cover-frame`），随后 `feat/click-av`，最后 `feat/vscode-ui`（UI 重构基于前项改动收尾）。

## 五、风险与依赖

- 黑帧判定阈值可能影响预览图与回放两处逻辑，两分支存在弱依赖，合并时保持先后顺序。
- 文本/音频依赖各引擎脚本数据完整性，个别引擎可能缺台词/语音资源，验收按「能解析到的资源范围内」放行，缺口单独记 issue。
- UI 重构改动面大（App.tsx / Replay.tsx / 新组件），需回归既有事件网格与回放页功能。
