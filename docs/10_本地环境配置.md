# 10 · 本地环境配置（环境变量与占位符）

> **适用对象**：下载源码后要在本机构建、运行测试，或执行 `tools/`、`m0/` 脚本的人。
> **红线**：仓库里不写任何本机绝对路径。需要本机目录的地方，要么读取环境变量，要么保留 `<...>` 占位符，由使用者按自己的机器填写。

## 1. 构建前提

- Go 版本以根目录 `go.mod`（根模块）与 `desktop/go.mod`（GUI 模块）为准。
- CLI（`cmd/ucgr`、`cmd/cgreplay`）与 GUI（`desktop/`，Wails v2）目前只能在 Windows 上构建，因为它们依赖 `internal/platform/win32`。
- 已验证：`GOOS=linux` 下，`internal/` 中除 `internal/platform/win32` 以外的包，以及 `tools/...`，可以编译。
- 发布与安装包流程见 `docs/08_发布流程.md`。

## 2. 环境变量

下面的测试变量未设置时，对应测试会跳过（`t.Skip`），不会报失败。

### 2.1 脚本（`tools/`、`m0/`）

| 名称 | 含义 | 怎么填 | 出现位置 |
| :--- | :--- | :--- | :--- |
| `UCGR_UNPACK_ROOT` | 解包根目录，其下每个游戏是一个 `<游戏名>解包` 目录 | 填解包输出的上级目录；也可以每次用 `--root` 传入 | `tools/verify_engine_dist.py` |
| `UCGR_GAME_ROOT` | 游戏库根目录，脚本用它拼出各游戏的原始归档目录 | 填包含各游戏原始目录的上级目录 | `tools/ks_reextract.py`、`m0/m0_census.py`；`tools/ks_fix9.py`（暂存，当前无法运行） |

### 2.2 Go 测试

| 名称 | 含义 | 怎么填 | 出现位置 |
| :--- | :--- | :--- | :--- |
| `UCGR_OGG` | 单个 `rogo.ogg` 样本文件 | 文件路径 | `internal/audio/vorbis`（`align_test.go`、`headers_test.go`、`decode_test.go`） |
| `UCGR_OGG_DIR` | Ogg 语料根目录，测试会遍历其中所有 `.ogg` | 目录路径 | `internal/audio/vorbis/decode_test.go` |
| `UCGR_REF_DIR` | PyAV 生成的参考 PCM 目录（内含 `rogo.s16`） | 目录路径 | `internal/audio/vorbis/decode_test.go` |
| `UCGR_BLUE_ROOT` | 「重返蓝鲸岛」解包根目录 | 目录路径 | `internal/catalog`（`text_corpus_test.go`、`speakers_test.go`） |
| `UCGR_BGI_DIR` | BGI 游戏解包根目录，递归扫描脚本 | 目录路径 | `internal/adapter/bgi/bgi_test.go` |
| `UCGR_ARTEMIS_DIR` | Artemis 游戏根目录，遍历 `.ast` | 目录路径 | `internal/adapter/artemis/artemis_test.go` |
| `UCGR_OTF` | 真实混淆字体文件 | `.otf` 文件路径 | `internal/platform/win32/font_windows_test.go`（仅 Windows） |
| `UCGR_HG3_SRC` | 存放 `.hg3` 的目录（必填） | 目录路径 | `internal/decode/hg3_test.go` |
| `UCGR_HG3_REF` | 用 GARbro 的 `GarHg3.exe` 转出的 PNG 目录（平铺，命名为 `<文件名>_0000.png`） | 目录路径；与 `UCGR_HG3_PIC` 二选一 | `internal/decode/hg3_test.go` |
| `UCGR_HG3_PIC` | 解包时已转好的图库目录，递归建立 PNG 索引后按同名匹配 | 目录路径；与 `UCGR_HG3_REF` 二选一 | `internal/decode/hg3_test.go` |
| `UCGR_HG3_LIMIT` | 只比对前 N 个 `.hg3`；`0` 或不设为全部 | 整数 | `internal/decode/hg3_test.go` |
| `UCGR_HG3_DUMP` | 把解码结果导出为 PNG 的目录；程序不会自动创建，需预先存在 | 目录路径 | `internal/decode/hg3_test.go` |

HG3 测试的规则：`UCGR_HG3_SRC` 必填；`UCGR_HG3_REF` 与 `UCGR_HG3_PIC` 二选一；任一条件不满足则跳过。

### 2.3 其他（一般无需设置）

| 名称 | 含义 | 出现位置 |
| :--- | :--- | :--- |
| `UCGR_AUDIO_DEBUG` | 非空即开启音频调试输出（stderr，前缀 `[audio]`） | `internal/audio/mf_windows.go` |
| `LOCALAPPDATA`、`APPDATA` | Windows 系统变量，决定数据目录；用户无需设置 | `desktop/app.go`、`desktop/export.go` |

## 3. 报告与文档中的占位符

报告与说明文字里的 `<...>` 不是可执行代码，照本机情况替换即可。

| 占位符 | 出现位置 | 怎么填 |
| :--- | :--- | :--- |
| `<素材根>` | `reports/S3_单事件端到端spike_重返蓝鲸岛_2026-10-18.md`（素材根表格） | 「重返蓝鲸岛」解包目录，通常与 `UCGR_BLUE_ROOT` 相同 |
| `<产物目录>` | 同上（产物路径） | 任意可写目录 |
| `<GO_BIN>` | 同上（PowerShell 的 `PATH` 设置行） | Go 安装目录下的 `bin`（含 `go.exe`） |
| `<repo>` | 同上（PowerShell 的 `cd` 行） | 本仓库的克隆目录 |
| `<游戏库根>` | `reports/引擎分布复核报告_2026-10-15.md` | 同 `UCGR_GAME_ROOT` |
| `<解包根目录>` | `reports/引擎分布复核报告_2026-10-15.md`；`tools/README.md` | 同 `UCGR_UNPACK_ROOT` |

## 4. 示例

以 PowerShell 为例。下面的设置只对当前会话生效；需要长期生效请在系统环境变量中设置。

```powershell
$env:UCGR_GAME_ROOT = 'D:\games'
$env:UCGR_UNPACK_ROOT = 'D:\unpacked'
$env:UCGR_OGG = 'D:\samples\rogo.ogg'
go test ./internal/audio/vorbis -count=1 -v
```

示例中的 `D:\` 路径只是占位，请换成自己的目录。

## 5. 本地生成的数据文件

以下文件不入库（见 `.gitignore` 与 `tools/README.md`），需要时在本机生成：

- `m0/engine_dist_verify.json`：`python tools/verify_engine_dist.py --root <解包根目录> --json m0/engine_dist_verify.json`。缺少它时，`m0/m0_census.py` 会退出并给出提示。
- `tools/ks_refs_out.json`、`tools/ast_refs_out.json`、`tools/cst_refs_out.json`：分别由 `python tools/ks_refs.py --all --json tools/ks_refs_out.json`、`python tools/ast_refs.py --all --json tools/ast_refs_out.json`、`python tools/cst_refs.py --all --json tools/cst_refs_out.json` 生成（命令同 `tools/README.md`）。
