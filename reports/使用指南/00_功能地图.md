# UCGR（统一 CG 演出回放库）· 功能地图

> 生成方式：实跑 `go run ./cmd/ucgr --help` / `go run ./cmd/ucgr engines` / `bin\ucgr.exe scan docs` / `go test ./internal/ir ./internal/prune ./internal/kif`，输出原文全部来自本次真实执行；文档依据标注为 文件:行。核对日：2026-11-16。

## 1. 一句话定位

把**已解包**的 galgame 资源按**原作自己的分割方式**（CG 鉴赏槽位、编号剧本、CG 表）扫成事件库，再用自研回放器逐帧重演完整演出（图层双缓冲 + 转场 + 对话框文本 + BGM/语音），并支持裁剪保留集、离线合成 GIF/静帧、GUI 导出 GIF/MP4 —— 依据 [README.md](../../README.md):8、[docs/09_发布说明_0.3.0.md](../../docs/09_发布说明_0.3.0.md):7-8。

## 3. 三种使用姿势

### 姿势 A · CLI 单条命令
```bash
go build -o bin/ucgr.exe ./cmd/ucgr          # README.md:61
bin/ucgr.exe scan <解包目录>                  # 体积盘点（README.md:64，已实跑验证）
bin/ucgr.exe events <解包目录> --out lib.json # 事件表（README.md:99）
bin/ucgr.exe play --script <xxx.cst> --assets <解包目录>   # 直接播一段（README.md:126）
```

### 姿势 B · 全流程脚本（导入→扫描→解包→事件→IR→回放→导出）
```bash
# 1) 解包（KIF 归档走 CLI；其余引擎先用各自工具/GUI 拖放解包）
bin/ucgr.exe unpack <归档.int> --out <解包目录>
# 2) 事件表
bin/ucgr.exe events <解包目录> --out lib.json
# 3) 引用 + 裁剪
bin/ucgr.exe refs  <解包目录> <脚本目录>
bin/ucgr.exe prune <解包目录> <脚本目录> --out <保留集目录>
# 4) IR
bin/ucgr.exe ir <解包目录> <脚本> --out ir.json
# 5) 离线导出（不弹窗）
bin/ucgr.exe replay ir.json --assets <解包目录> --gif out.gif
bin/ucgr.exe replay ir.json --assets <解包目录> --render frames/ --at 0,1000,2000
# 6) 窗口实时播放
bin/ucgr.exe play ir.json --assets <解包目录>
```

### 姿势 C · GUI
**本仓库有 GUI，两套**：
1. `cmd/cgreplay` → `bin\cgreplay.exe`：Win32 原生窗口，单游戏，双击事件即播（docs/05:75-77）。
2. `desktop/` → `desktop\build\bin\cgreplay-ui.exe`（Wails v2 + React，多游戏库 + 导出任务中心，v0.4.0，desktop/wails.json:3、16；构建命令 `cd desktop && wails build -s`，docs/12:86）。

## 4. 数据从哪来到哪去

```
[源游戏目录]                      未解包的 galgame 本体（.xp3/.pfs/.int/BGI.hvl/NPA/NSA…）
     │  各引擎解包工具 / GUI 拖放（desktop unpack.go:82-143）/ ucgr unpack（KIF）
     ▼
[解包目录]                        明文脚本(.ks/.ast/.bs/.cst/.scn/nss…) + 图片/音频
     │  ucgr events（internal/library 多引擎扫描）
     ├──► [事件库 lib.json]        CG 事件 + 场景事件（GUI 加载用）
     │  ucgr refs / prune（internal/prune）
     ├──► [保留集目录]             只够重演 CG 事件的最小资源集
     │  ucgr ir（internal/ir，校验 V1~V9）
     ├──► [ir.json]               图层/时间轴/演出台本 show/文本/语音/分支
     │  ucgr replay --render/--gif ── internal/replay + internal/decode（掩码 JPEG）
     │  ucgr play / cgreplay.exe / cgreplay-ui.exe ── internal/player + internal/platform/win32
     ▼
[渲染产物]  PNG 帧目录 / GIF / MP4 / 截图（派生物，不碰库内原资产，docs/06:134）
     │
     ▼
[中心库]  %LOCALAPPDATA%\cgreplay-ui\catalog.db（SQLite：games/events/favorites/speakers/recent，
          desktop/catalog.go）＋ 封面 bin/covers/*.png ＋ 登记表 games.json（internal/registry）
```
设计层面的完整流水线（M0 清点→摄入→裁剪→打包→入库→两段删除→回灌）见 [docs/05](../../docs/05_流水线设计.md):92-117。
