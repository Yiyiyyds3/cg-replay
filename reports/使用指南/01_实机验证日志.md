| `ucgr events <解包目录> [--out]` | 目录里有 `.ks/.scn/.ast/.bs/.cst/nscript.dat/Script.pac/nss.npa` 之一 | ✅ 仅 kirikiri 解包样本成功（11 场景）；❌ unity / rmmz 目录失败 | 输出事件库 JSON（`schema: 2`） |

| `ucgr replay <ir.json>` | ir.json 来自 `ir` / 桌面端 | ✅ exit 0，打印时间轴 | 只吃 IR；吃 events.json 会空转 |
| `ucgr replay <ir.json> --assets --render --at` | 素材根目录存在 | ✅ exit 0，出 2 张 PNG | 离线出帧，不弹窗 |
| `ucgr decode <图片>` | 仅 TLG5 / JPEG / HG3 | ❌ `.rpgmvp` 与明文 `.png` 均失败 | 见第 8 节，CLI 未接 `DecodeImage` |
| `ucgr play` / `probe` / `refs` / `prune` / `unpack` / `audio` | — | ⏸ 本次未测 | 手册若写，需另行实测，别抄用法页当结论 |
| `go test ./... -count=1` | — | ✅ exit 0，30 ok / 0 FAIL | 全绿 |

一句话链路（kirikiri，已实测走通）：

```text
scan（可选，看体积） → events（出事件库） → ir（选一个脚本压成 IR） → replay（时间轴 / --render 出帧）
```

## 11. 踩坑：失败命令及原因

| # | 失败命令 | 现象 | 原因 | 绕法 |
|---|---|---|---|---|
| 1 | `ucgr --help` | 打印完整用法后 `exit status 2`，shell exit 1 | `usage()` 后按「参数不足」返回 2 | 看用法可以，判死活用 `ucgr engines` |
| 2 | `ucgr events "D:\UCGR_Work\unitycg\MuniangTiaojiao"` | `错误: 未知引擎 "unity"（支持：artemis / bgi / … / scn）` | 目录里的 `ucgr-convention.json` 写了 `engine_id=unity`，但 `adapter.ConventionByEngine` 没有 unity 分支（`engines` 也只有 8 个 id） | 无 CLI 绕法：unity CG 索引目前只能走桌面端 / library 层；CLI 的 events 对 unity 不可用 |
| 3 | `ucgr events "<rmmz 源目录>"` | `错误: 没有找到可回放的剧本（.ks/.scn/…）` | rmmz 剧本是 `www/data/*.json`，不在引擎探测的剧本后缀清单里，连 engine id 都判不出来 | 同上：pass 清单里 37 条 rmmz 款都走不通 `events` |
| 4 | `ucgr ir "<解包目录>" "data/scenario/SKAE_001r.ks"` | `错误: 读不到脚本 data/scenario/SKAE_001r.ks` | 脚本参数按**当前工作目录**解析，不会拼到解包目录后面 | 传绝对路径 |
| 5 | `ucgr replay "reports\使用指南\demo\events.json"` | `⚠️ IR 校验未过（3 条）` + `事件 0 个`，但 exit 0 | `replay` 只认 IR 结构；事件库不是 IR | 先 `ucgr ir` 生成 ir.json 再 replay；别把 exit 0 当成功 |
| 6 | `ucgr decode "...001.rpgmvp" --out ...` | `非 TLG/JPEG/HG3 文件（魔数 "RPGMV…"）` | CLI 走 `decode.Decode`；`RPGMV` 头分支只在 `decode.DecodeImage` 里 | 无 CLI 绕法；rmmz 加密图当前只能用别的链路（或等修） |
| 7 | `ucgr decode "..._0000_a3-1.png" --out ...` | `非 TLG/JPEG/HG3 文件（魔数 "\x89PNG…"）` | 同上，`Decode` 不认 PNG | 明文 PNG 不需要 decode，直接用图 |
