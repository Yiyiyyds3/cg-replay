## 3. 判定怎么记

1. 画廊里 `←`/`→` 切到当前款，按 **`1`＝好、`2`＝小问题、`3`＝严重、`4`＝待查**（焦点不在输入框/下拉时生效），细节写在每款备注框；
2. 点页面顶部「**导出 CSV**」→ 下载 `review-verdicts-YYYYMMDD-HHmm.csv`（53 行全量、UTF-8 BOM，Excel 不乱码）；
3. 先备份旧表，再用下载文件覆盖 `打分表.csv`：

```powershell
# 备份成 打分表_YYYYMMDD.csv
Copy-Item reports\人工抽检\打分表.csv ("reports\人工抽检\打分表_{0}.csv" -f (Get-Date -Format yyyyMMdd))
# 用画廊导出的 CSV 覆盖正式打分表
Copy-Item "$env:USERPROFILE\Downloads\review-verdicts-*.csv" reports\人工抽检\打分表.csv -Force
```

判定只有落进 `打分表.csv`（或其日期备份）才算数；localStorage 只是浏览器里的草稿。

## 4. pass ≠ 画质达标

pass 是验收流水线的**工程结论**（目录在、扫描跑得通、结构成立），不等于图本身达标：加密图、空白帧、近似重复、极小图、编号断裂这些只有人眼能定——rmmz 预筛实测 19 款全加密（77,551 张 .rpgmvp/.png_），画廊里显示「加密图不可渲染」占位块，这几款要先走解密/导出链路、把明文目录喂给画廊后才能真的看。

## 5. rmmz 全加密款怎么办

`预筛指标_rmmz.json` 已由 `review-prescreen -from-manifest` 生成；其中 19 款全加密、机器读不到像素，sev3 是「读不了」的占位判定。解密导出明文后，重跑同一条命令拿真指标：

```powershell
go run ./tools/review-prescreen -from-manifest "reports\人工抽检\pass清单.json"
```
