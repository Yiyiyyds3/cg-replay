# 问题款清单

人工抽检产出：凡判定为「严重（3）」或「待查（4）」且确认有实际问题的款，在下方按模板加一节。
判定「好 / 小问题」的款只记在 `打分表.csv`，不进本清单。每款一节，标题格式 `## idNN · 款名`（NN 用打分表 id）。

每节字段：

- **判定**：画廊 1-4 键对应的结论（本清单只收 3 严重 / 4 待查）
- **问题类型**：加密图 / 空白帧 / 重复冗余 / 极小图 / 尺寸异常 / 序列断裂 / 目录缺失 / 其他
- **证据**：具体文件名（复制画廊卡片下的 basename）或截图路径，能让人不重跑就定位
- **处置**：留观 / 需解密重导 / 需重新导出 / 剔除 pass——写清下一步动作
