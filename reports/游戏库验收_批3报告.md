## 六、进度口径（三项 + 两项，逐项算式）

| 项 | 算式 | 值 |

| **进行中 P（partial）** | 批1 partial 0 + 批2 partial 2 + 批3 partial 3 = 0+2+3 | **5** |

**三项汇报数**：**累计已验收 20 ／ 卡点跳过 23 ／ 剩余 52（共 117）**；另列 **失败待修 17 / 进行中 5**。

闭合校验（三条都要对）：

```
状态和： 20(验收) + 23(跳过) + 17(待修) + 5(进行中) + 52(未跑) = 117  ✅
已跑：   20 + 23 + 17 + 5                              = 65   ✅
批次和： 5 + 16 + 44                                    = 65   ✅
剩余：   117 − 65                                       = 52   ✅
逐批和： (1+0+1+3) + (5+2+4+5) + (14+3+12+15) = 5+16+44 = 65   ✅
```
